Game Systems

🌊 Wave System

  • Wave 1 เริ่ม 12 ตัว +4/wave
  • Boss ทุก 5 Waves
  • HP/ATK ศัตรู ×1.11 ต่อ Wave
  • Spawn ทุก 280ms delay
  • Timer 3s ระหว่าง Wave

👾 Enemy Types

  • 🟢 Zombie — ช้า, HP น้อย
  • 🟣 Ghoul — เร็ว, Claws
  • ⚪ Skeleton — เร็วมาก, Melee
  • 🟤 Zombie Archer — Range 220px
  • 🔴 Undead Lord — Boss, HP 900

⬆️ Level System

  • EXP ต่อ kill: 15–220
  • NextExp ×1.4 ต่อ Level
  • HP +22, ATK +6, MP +12
  • HP ฟื้น 55 เมื่อ Level Up
  • Attack cooldown ลดตาม Lv

🎮 Controls

  • Virtual Joystick (touch ซ้าย)
  • SKILL button (touch ขวาบน)
  • ATK button (touch ขวาล่าง)
  • WASD / Arrow Keys
  • Z = Skill, X = Attack

⚡ Skill System

  • Auto-attack: range 75px
  • AOE Skill: range 140px
  • Skill cost: 30 MP
  • Skill CD: 5 วินาที
  • MP Regen: 6/วินาที

💊 Drop System

  • HP Potion — drop 18%
  • MP Potion — drop 12%
  • HP Heal: 35 + Lv×6
  • MP Restore: 45
  • Pickup range: 26px
